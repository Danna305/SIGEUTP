Todo el proceso de estadías en un solo sistema

Alumnos, asesores y coordinación trabajan en la misma plataforma: expedientes digitales, asignación de asesores, seguimiento académico y un portal móvil para el alumno.

Arquitectura general

Los cuatro módulos comparten el mismo diseño, el mismo inicio de sesión y una sola base de datos.

Frontend webAplicación web progresiva con el diseño común SIGEP.
Aplicación móvilSe instala desde el navegador en Android y iPhone.
BackendAPI REST que atiende a los cuatro módulos.
Base de datosUna sola base compartida por todo el sistema.
